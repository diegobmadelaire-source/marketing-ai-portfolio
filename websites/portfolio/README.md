# Portfolio — Diego Bogado Madelaire

Sitio personal de Diego Enrique Bogado Madelaire: estudiante de Marketing y freelancer, presentado como el punto de entrada profesional a sus proyectos, especialidades y contacto.

## Objetivo

Comunicar el posicionamiento de Diego como **marketer que utiliza tecnología e IA para resolver problemas de negocio** (no como programador), orientado a potenciales clientes y oportunidades profesionales.

## Estructura

- Hero con identidad, propuesta de valor y accesos directos a redes/contacto.
- Sobre mí.
- Especialidades (7 áreas).
- Proyectos destacados: Pizzeria Demo (real, desplegado), Blush Bar (proyecto académico), y dos espacios reservados para futuros proyectos de IA y automatización.
- Servicios.
- Stack y herramientas.
- Proceso de trabajo.
- Contacto y footer.

## Stack técnico

HTML, CSS y JavaScript vanilla — sin frameworks, siguiendo el mismo criterio que `websites/pizzeria-demo/`: velocidad, claridad y mantenimiento simple.

## Contenido y veracidad

Todo el contenido está tomado o adaptado del README raíz del repositorio y de información provista directamente por Diego. No se inventaron clientes, resultados, métricas, campañas ni años de experiencia. Blush Bar se presenta explícitamente como un **proyecto académico**, no como un cliente real.
