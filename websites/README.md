# Websites

Guarda aquí sitios web, landing pages, portfolios, micrositios y prototipos web.

Cada carpeta de proyecto debería indicar el propósito del sitio, público objetivo, tecnologías utilizadas, instrucciones para ejecutarlo y una captura o enlace de demostración cuando esté disponible.

No coloques aquí una página web para este repositorio: este espacio es únicamente para sitios que desarrolles como proyectos independientes.
