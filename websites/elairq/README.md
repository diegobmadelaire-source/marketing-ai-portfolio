# ELAIRQ - SET 01 / MONOLITH

Conceptual product and brand experience for ELAIRQ, a contemporary footwear hardware label.

The site is a static, responsive HTML/CSS/JavaScript prototype. It does not include a cart, payments, Shopify integration, or product claims intended as final specifications.

The five local product visuals in `images/` were generated as concept-design imagery and can be replaced with final product photography when available.

Open `index.html` in a browser to view the prototype locally.
