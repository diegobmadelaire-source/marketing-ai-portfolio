# Automation

Guarda aquí automatizaciones, diagramas de flujo, integraciones y scripts orientados a mejorar procesos.

Ejemplos:

- Flujos para captación y seguimiento de leads.
- Automatización de reportes o tareas de contenido.
- Integraciones entre formularios, hojas de cálculo, CRM y herramientas de IA.

Cada proyecto debe explicar qué problema automatiza, los pasos del flujo, las herramientas necesarias, cómo configurarlo y qué información sensible no debe versionarse.
